# M1A review — d746cf9

Branch `feature/arena-vnext-mobile-jenny`, parent `f310ee6`. Implementation commit `d746cf9`.

## What shipped

Public entry is Welcome, sign up, sign in, forgot password, reset, and seven onboarding steps, then the VNext shell: Feed, Discover, +, Work, You. Map is not a tab. Jenny is not a tab. Inbox stays in the header.

Public signup offers only "Join as a person" and "Create a company account". Recruiter, hiring manager, and platform admin are not on the form. Invite acceptance is unchanged at `/auth/invite/[token]`, which re-exports the existing invite page.

Onboarding does not invent a profession, city, skills, or biography. A title is sent only when the person also chooses a field. Location is approximate, a typed area, or none. Gachibowli appears only if `NEXT_PUBLIC_ENTRY_FIXTURE_AREA` is set. Career visibility stays off unless the person turns it on. `setOnboarded()` runs only after `getMyProfile()` returns.

The first feed says what was chosen and shows "Nothing here yet" when the API returns an empty list. A failed request says "The feed did not load" and offers Try again. Rows are marked DEMO only when the payload includes `demoContent`.

## Known limitations

- Introduction, availability, personal interests, and a photo stay on the device. The profile API has no public field for them, and the privacy step says so.
- The optional career layer does not yet collect résumé, notice period, work mode, or compensation. Jenny does not draft or publish those fields.
- If the person types a title and a field, the details request sends `experienceYears: 0` and `rateFloor: 0` because the API requires those numbers. They are not shown as a biography.
- Discover does not yet have a List/Map switch. The old `/map` route still exists and is not in the bottom bar.
- The feed card is still the simple card. The richer per-kind card is not in this commit.
- A Google account that is new in this browser is not forced through onboarding. Email sign-up is.
- `demoContent` is rendered when the API sends it. This branch does not include the unmerged P0 backend, so a preview pointed at today's production API will not badge seeded rows until that field is deployed.
- The protected preview was not verified against a live signup in this review file. See the handoff after the preview deploy.
