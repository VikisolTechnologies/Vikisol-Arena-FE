## 11. Performance and bundle

Decoded JavaScript collected on that `/home` load was 1,493 KiB. That figure is uncompressed and includes every script response, so it is not the gzipped initial-chunk number. The 200KB gzipped gate was not re-measured here and stays open. It was not loosened.

## 12. Console and network

After the allowlist change, `GET /api/v1/feed` returned 200 with `Access-Control-Allow-Origin` set to the git preview origin, and the feed rendered. The API-down strings were absent on `/home` and `/discover`.

During the phone sweep the console reported one 403 and one 404. The only 404 URL captured was `/this-route-does-not-exist`. Several `/_rsc` requests failed with `net::ERR_ABORTED` because the crawler navigated away. Those are not failed API calls. A later recruiter sign-in captured no 403 responses. Sentry ingest was not separated from first-party failures in the first sweep.

`https://evil.example` is still rejected (403, no allow-origin). `https://arena.vikisol.in` and `https://preview-arena.vikisol.in` still receive their own allow-origin.

## 14. Demo-content honesty

Preview landing copy is: “Jenny helps when there is something real to say. Counts on this page are the live ones, or the sentence stays without a number.” It does not say “all real people nearby”.

Production `https://arena.vikisol.in/` still contains “all real people nearby”.

On the preview, `/discuss/communities` labels “Careers & Job Switch” as DEMO CONTENT. The guest feed cards that were on screen (Hello, the photography walk, the book club, the study group, football, the Swiggy project) had no DEMO CONTENT badge in the screenshot. A visitor can read those as live network activity. Some of that is seeded demo content mixed with a real “Hello” post. This pass did not separate each card’s demo flag in the API payload.

Recommendation, not implemented: do not treat this as agreed. Either keep demo rows out of public counts and unbadged cards, or label the whole preview as a demonstration. Do not ship the production “all real people nearby” line against a feed that still contains seeded rows.
